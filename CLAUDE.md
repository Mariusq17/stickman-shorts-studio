# Stickman Video Studio - project guide for Claude

The owner talks in **Romanian**; answer in Romanian. Videos are produced in **English**.

## What this repo is
1. **Stickman Video Studio** (`app.py`, `stickman_studio/`): offline Streamlit app that makes
   stickman shorts from template scripts (Piper/SAPI voices, music, subtitles). Started with
   `START_STUDIO.bat` on Windows. Stable; not the current focus.
2. **Explainer engine** (`stickman_studio/explainer/`): the main product now. Premium 2-2.5 min
   "build it step by step" explainers (2.5D isometric, pure Python, offline render, 1080x1920).
   Reference: `explainer/elevator.py` -> rated **9.5/10** by the owner.
   Library of reusable pieces: `explainer/lib/` - documented in `explainer/LIBRARY.md`.

## How to handle requests
| The owner asks for... | Do this |
|---|---|
| a status / "what's next" / start of a session | skill `studio` (mode start) |
| new video ideas | skill `explainer-ideas` (ideas are generated by Claude, saved in `ideas/IDEAS.md`) |
| a video from their own idea/topic/notes/video type | skill `explainer-from-idea` -> then `explainer-video` |
| make / render one or several videos, continue a batch | skill `explainer-video` |
| end of session / "save progress" | skill `studio` (mode wrap-up) |

## Owner preferences (keep this list updated - it is the project's memory)
- Quality first: premium, viral-ready, but stylised (no realistic textures).
- Script formula from the reference channel: hook = first build step, problem -> fix -> term loop
  every ~10 s, exaggerated comparisons, everyday "aha" payoff, "Congratulations, you just built a..."
  + joke + CTA "Follow for more".
- Voice: Piper, **1.2x** (1.4 was too fast, 1.3 still a bit fast).
- Text ON objects (screens, cards, signs, labels on boxes) must be printed in the surface's perspective
  (`kit.plane_text`, warped onto the plane) and must fit inside the object (`max_w`/`max_h`); never
  screen-aligned text floating on a slanted surface. Check it in previews at close zoom.
- Keywords only (no full subtitles), appearing exactly when spoken, readable ~1-1.5 s, smooth.
- Loves: side pop-ups, arrows, progress bars/meters, graphs, counters, the FIXES tracker, smooth
  camera transitions. Dislikes: static screens while talking, objects showing through walls,
  render glitches, ugly CTA buttons.
- No GPU (work laptop, Intel Arc) -> Blender path was tested (`blender_render.py`) but parked;
  stay on the Python 2.5D renderer.
- Deliver each finished MP4 immediately (SendUserFile); commit + push code before long renders.
- Wants the process as automatic as possible so they can work on other things meanwhile.
- Prefers working in fresh sessions per batch (cheaper/faster than one huge chat); expects the
  `studio` skill + this file to carry all context between sessions.
- Cares about token/credit usage: keep previews targeted (contact sheets at ss=1), avoid re-reading
  big files needlessly, deliver partial results if a batch can't finish.
- Feedback history: elevator v1 6.5/10 (static hook, keywords timing, empty background, ugly CTA)
  -> v2 8.5-9 (narration-synced visuals, pop-ups) -> v3 (fixed see-through objects, 1.3x)
  -> v4 9.5/10 (spring camera, motion blur, shadows, mascots v2, tracker, graphs).
  card_tap (2026-11-20): liked it; text on objects was not in perspective / not fitting -> fixed in engine.

## Commands
```bash
python -m stickman_studio.explainer.render --list
python -m stickman_studio.explainer.render <slug> --preview 0.5,3,10,30      # contact sheet
python -m stickman_studio.explainer.render <slug>                             # full render (~20 min)
python -m stickman_studio.explainer.render --batch a b c --jobs 2             # resumable batch
python -m pytest -q tests                                                     # app tests
python -m stickman_studio.voices --download en ro                             # Piper voices (once)
```
Container notes: Hugging Face may be blocked (Piper EN voices come from GitHub mirrors; the RO voice
needs Hugging Face). Install `espeak-ng` + `piper-tts` if missing. Rendering costs no tokens.

## Keep the system learning
Whenever the owner gives feedback or a new preference, update the section above, the relevant
skill (`.claude/skills/*`) or `LIBRARY.md` in the same session, and commit. New generic visuals go
into `explainer/lib/`. Never delete history in `ideas/IDEAS.md`; update statuses.
